## The project charter

This adoption record, [00-OBJECTIVE.md](00-OBJECTIVE.md) and [00-BYLAW.md](00-BYLAW.md) form the charter. The objective defines the product and acceptance criteria. The bylaw defines Fedora, Podman, agent selection and operating boundaries. The README describes actual status and verified use; it cannot silently amend the charter.

The product owner controls charter amendments and merges. Shared rules are edited in the standards repository, not redefined here. An exception or version change requires explicit owner direction and an adoption update that resolves conflicts and identifies any implementation gaps.

## Loading the standards

Agents must read both pinned documents through authorized access before relying on them. A verified local cache of the exact commit is acceptable. If neither is available, report the access blocker; do not substitute remembered rules or the latest central version.

This public repository contains references, not private standards text. Copying that text here requires explicit authorization to publish it. Do not put access credentials in this file or the repository.

## Restart boundary

The November 10, 2026 charter restart remains in effect. Historical code and documents are reference material, not binding instructions. The old constitution in `oso-gato/homelab-root` is not imported by this adoption. Existing Git history and tags are preserved, and no other repository's adoption is changed.
